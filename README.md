# ذهب AI — لوحة تحليل XAU/USD

واجهة عربية متجاوبة مع الآيفون، قابلة للنشر على GitHub Pages. تتضمن مخطط TradingView، روابط لمصادر أخبار اقتصادية أصلية، وحاسبة مخاطرة.

## نشر الموقع من الآيفون
1. نزّل ملف ZIP وافتحه في تطبيق Files.
2. أنشئ مستودعاً جديداً في GitHub من Safari، مثلاً `gold-ai-dashboard`.
3. ارفع الملفات الثلاثة `index.html` و`styles.css` و`app.js` إلى جذر المستودع. ارفع `README.md` اختيارياً.
4. من المستودع افتح **Settings → Pages**.
5. اختر **Deploy from a branch** ثم `main` و`/(root)` ثم **Save**.
6. انتظر حتى يظهر رابط الموقع ضمن صفحة Pages.

## حدود النسخة الحالية
- مخطط TradingView مضمّن من `OANDA:XAUUSD`. قد تختلف الأسعار والتأخيرات حسب مزوّد البيانات وإعداداته، لذلك قارنها بسعر وسيطك.
- لا يوجد اتصال مباشر بـ MetaTrader 5 في GitHub Pages. التكامل مع MT5 عادةً يحتاج EA/خدمة وسيطة أو API من الوسيط.
- لا توجد حالياً إشارات شراء/بيع آلية أو أخبار ملخّصة بالذكاء الاصطناعي؛ الواجهة تعرض ذلك بوضوح ولا تختلق سعراً أو توصية. تفعيل هذه الوظائف يتطلب API لبيانات الأسعار/الشموع، وخلفية آمنة لمعالجة البيانات والأخبار، ومفتاح خدمة ذكاء اصطناعي محفوظ على الخادم وليس داخل JavaScript العام.
- GitHub Pages يستضيف ملفات ثابتة فقط؛ لا تضع مفاتيح API أو كلمات مرور الوسيط في المستودع.

## خطة التفعيل
1. اختر مزود بيانات XAU/USD يصرّح بوضوح بالتوقيت والتأخير ويدعم بيانات OHLC.
2. أنشئ backend (مثلاً Cloudflare Workers أو Vercel Functions) لحفظ الأسرار وجلب الأسعار والأخبار.
3. احسب المؤشرات على بيانات فعلية، وحدّد شروط الإشارة واختبرها تاريخياً وخارج العينة قبل عرض دقة مزعومة.
4. أضف تنبيهات Push/Telegram بعد موافقة المستخدم، مع حدّ للمخاطرة وسجلّ للإشارات.
